# 项目子智能体与任务分工

**执行状态：**用户已完成 PRD 审阅并接受风格稿。Web、移动壳和生态调研任务已启动；测试、Cloudflare 部署及 App 打包安排在功能完成后执行。

## 1. 协作原则

- 主协调智能体拆分任务、处理意见、管理接口/文件边界、合并结果并对照验收标准。
- 用户已确认产品决策，主协调智能体据此执行已批准范围。
- 网站与 App 同步开发；Web 是共享课程界面，React Native 只做 WebView 壳及必要原生交互。
- 不创建产品后端、账号或数据库；用户学习状态只存每台设备的浏览器/WebView 本地存储。
- 测试智能体必须实际使用浏览器控制和 iOS/Android 模拟器；部署智能体负责最终 Cloudflare 发布。
- 教师智能体只能起草内容；课程代码经验证、技术和教学审校后才可交付。

## 3. 阶段与任务分配

### 阶段 0：审阅已完成，当前实现阶段

- PRD 子智能体整理用户、范围和验收草案。
- 课程架构子智能体提出课程顺序和内容模板。
- 技术架构子智能体提出技术方案及约束。
- 图像生成提供风格稿，交由用户审阅。
- 主协调智能体已依照用户回复更新 PRD/规格，启动 Web/App 与生态调研任务。

### 阶段 1：规格批准后建立骨架

1. 主协调智能体冻结 PRD 与架构决策、确认路由和本地数据格式。
2. Web 体验智能体与 React Native 壳智能体并行初始化工程；先用稳定开发地址连通 WebView。
3. 生态调研智能体确定库清单；内容/静态数据智能体交付 schema；教师智能体完整编纂主要技术栈课程，并为三方库写轻量速览。
4. Web 端确定响应式断点、主要流程和本地存储结构；App 壳补上原生加载/返回/安全区域。

### 阶段 2：双端功能完成

1. Web 体验智能体实现路线选择、课程目录与详情、搜索筛选、进度标记和本地保存。
2. React Native 壳智能体连入相同的开发/预览网站，处理加载状态、断网/加载失败提示、外链与回退行为。
3. 内容/静态数据智能体把经审阅的课程内容纳入静态构建；教师智能体继续分章节起草。
4. 技术审校者运行关键代码示例，教学编辑审校文案和可读性。

### 阶段 3：测试、部署和交付

1. 测试智能体先在 Codex 浏览器控制环境操作桌面和移动视口，覆盖主要学习流程和本地进度恢复。
2. 测试智能体再安装并操作 iOS Simulator、Android Emulator 中的 App，验证 WebView、本地数据、状态栏/安全区域、返回、外链和错误提示；有真机条件时补充实际设备测试。
3. 缺陷由对应 Web/App 智能体修复，测试智能体复测并记录通过项/未覆盖项。
4. 部署智能体执行最终构建和 Cloudflare Workers Static Assets 发布，验证正式 HTTPS 地址、SPA 深路由、静态内容、响应式页面与本地进度流程。
5. 主协调智能体整理 Cloudflare 地址、App 测试构建物、浏览器/模拟器覆盖、已知限制和交付说明。App Store/Google Play 提交只有在 PRD 明确批准后才纳入。

## 4. 测试智能体的操作要求

- 优先使用 Codex 提供的浏览器控制功能打开本地预览和 Cloudflare 预览/生产地址，执行可见 UI 操作。
- 至少覆盖一套桌面视口、一套窄手机视口、触控/键盘操作和主要浏览器刷新行为。
- 必须运行 iOS Simulator 与 Android Emulator 的 App 测试；若设备环境或依赖不可用，列出具体阻塞和未测平台，不能把 Web 模拟说成 App 原生测试。
- 检查本地完成状态在网页刷新/App 重启后保留；确认 Web 浏览器和 App WebView 的状态彼此独立且没有网络上传。
- 每条缺陷应包含设备/浏览器、视口或系统版本、操作步骤、预期/实际结果和截图；修复后回归。

## 5. 部署智能体的操作要求

- 网站使用 Vite 静态构建；默认目标为 Cloudflare Workers Static Assets/Wrangler。
- 完成配置核对、生产构建、发布和生产烟测；使用 Cloudflare 默认 `workers.dev` 地址。
- 不把 Cloudflare API Token、签名材料或其他密钥写入仓库、课程内容或日志。
- 若没有授权的 Cloudflare 会话/凭据，准备好可复核的 Wrangler 配置和部署命令，并明确说明发布被凭据阻塞；不声称已部署。
- 交付版本/提交、部署时间、目标地址、烟测结果和回滚/恢复方式。

## 6. 文件与交付边界

- Web 路由和视图归 Web 体验智能体；Expo 原生文件与 WebView 配置归 React Native 壳智能体。
- 课程源按明确章节分配负责人，稳定课程 ID 由内容 schema 校验。
- 所有学习者状态写入本地存储；如需更改存储格式，由 Web 体验智能体和主协调智能体共同确认，不新增云端数据服务。
- 教师智能体生成的内容保持 `draft`，必须经代码验证、技术审校、教学编辑审校后才可交付。
- 每项任务提交文件清单、假设、验证结果和未解决问题。

## 7. 审核门槛

1. PRD、技术规格、风格稿、Cloudflare 默认地址及 App 打包范围已由用户确认。
2. 主协调智能体据确认内容维护执行清单和验收标准。
3. Web 与 App 功能完成后，由测试智能体按浏览器和双平台模拟器要求实测。
4. 网站通过 Cloudflare 生产烟测后，交付网站地址和 App 安装包；不提交应用商店。

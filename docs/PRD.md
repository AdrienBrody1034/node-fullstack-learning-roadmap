# Node 全栈学习计划产品 PRD

**状态：用户已完成本轮审阅；以下为确认后的开发基线。** 设计风格稿已接受。实现网站与 iOS/Android App 当前版本后，完成测试、Cloudflare 部署和 App 安装包交付。

## 1. 产品概述

中文 Node 全栈学习计划网站与移动 App。网站兼容桌面和手机；App 使用 React Native WebView 壳展示同一套响应式网站。产品帮助已有少量编程基础的学习者系统掌握 Node.js 全栈开发，同时保留补基础入口。学习路线按阶段组织，每个阶段可包含多个同类或可比较的技术栈节点。

主流技术栈课程覆盖 JavaScript、TypeScript、Node.js、React、Next.js、NestJS、React Native 等，要求内容完整、通俗且高质量。生态第三方库按调研结果选择，只讲主要功能、用途和易懂代码示例。

## 2. 已确认产品决策

- 首要用户：已有少量基础的转行/进阶开发者；保留补基础入口。
- 网站与 iOS/Android React Native WebView 壳同步开发；网站同时适配桌面和移动浏览器。
- 不做账号、不接数据库、不做后端 API；学习进度和偏好只保存在前端设备本地。网站与 App 存储彼此独立，不同步。
- 不提供本地数据导入/导出备份。
- 主要技术栈全覆盖且内容深入；第三方生态库介绍主要功能并给代码示例即可。
- 用户自选慢/中/快三档学习节奏，并可随时切换，不影响路线和已完成进度。
- 讲解使用中文，代码以 TypeScript 为主，中文解释和代码示例都要丰富。
- 生态库由项目团队查阅社区生态后确定，不需要用户指定。
- 网站部署到 Cloudflare 默认地址；App 不上架，交付可安装构建包。
- 用户接受当前风格稿。

## 3. 用户问题与核心流程

学习者需要弄清楚技术先后关系、多个同类框架怎么选择、生态库解决什么问题，以及如何把知识变成能运行的项目。路线不仅列技术名词，还要说明每个节点的目的、前置和实作结果。

核心流程：

1. 选择目标方向和基础程度；未知技能可走补基础节点。
2. 浏览分阶段路线。阶段内可看到并列技术节点、依赖关系、对比节点和综合项目。
3. 选择慢/中/快三档学习节奏，设置随时可更改。
4. 打开课程，阅读中文讲解和 TypeScript 示例，完成练习或项目任务。
5. 标记学习状态；路线、节奏和进度保存到当前浏览器或 App WebView 本地。
6. 查看本地学习面板与按先修关系推荐的下一步。

清除浏览器/App 数据或卸载 App 可能删除学习记录。Web 浏览器和 App WebView 不共享记录；App 加载网站需要网络。

## 4. 课程范围与路线结构

课程完整覆盖以下主要技术栈：

- **基础：**命令行、Git、HTTP/Web、HTML/CSS、JavaScript、TypeScript。
- **Node 后端：**Node.js 运行时、模块/异步/I/O、HTTP、错误处理、日志、配置、安全和测试；Express、Fastify、NestJS 作为同阶段并列节点比较与实作。
- **数据与 API：**SQL、关系型数据库/PostgreSQL、数据校验、ORM/查询工具、认证授权概念、REST、测试。
- **React 前端：**组件、状态、表单、路由、服务端数据、样式和可访问性；生态专题按解决的问题分节点。
- **Web 应用框架：**React SPA/React Router 与 Next.js 并列作为相互关联节点；Next.js 完整讲解 App Router、服务端/客户端边界、数据获取、缓存和部署。
- **移动开发：**React Native 与 Expo，涵盖组件布局、导航、原生能力、持久化、调试和构建。
- **工程实践：**贯穿项目、测试、部署、错误处理、安全、可维护代码和复盘。

阶段采用“阶段 → 主题/技术节点 → 课程单元”结构。并列节点表示同一阶段的不同方案或技术，不把所有节点压缩成单一路线；用标签说明共同概念、差异、先修和需要完成的实践。主要技术栈都有系统课程；库节点保持轻量。

候选生态主题包括：

- Node：Express、Fastify、Zod、Prisma/Drizzle、Pino、Vitest/Jest、Supertest、Redis/BullMQ。
- React/Next：TanStack Query、React Hook Form、Zustand/Redux Toolkit、Tailwind CSS、主流组件方案、Playwright。
- React Native：Expo、Expo Router/React Navigation、React Native Reanimated、Gesture Handler、测试工具及平台调试生态。

这只是候选而非已定清单；最终条目见[生态调研记录](./curriculum-ecosystem.md)，按社区采用证据、维护状态、学习价值与功能重叠筛选。

### 贯穿项目

以“学习计划管理器”为教学主线，从 CLI、Node API、React Web、Next.js 应用，到 NestJS 后端和 React Native 客户端逐阶段扩展。该教学项目可涉及账号/数据库，但本产品自身不实现账号或数据库。

## 5. 学习节奏

- 提供 **慢 / 中 / 快** 三档，不设置固定课程完成期限。
- 档位控制每周建议任务量与每日/每周节奏提示，不减少或隐藏主流技术课程。
- 学习者可随时切换档位；只调整未来计划，不重置已完成节点或本地进度。
- 建议起始量：慢档每周约 2–3 小时，中档约 5–7 小时，快档约 8–12 小时。此数字是节奏建议而非课程时长承诺，可在实现前根据内容量校准。

## 7. 内容质量规范

主要技术栈课程使用统一教学模板：目标、先修、实际问题、通俗解释、完整上下文示例、文件名/依赖/运行命令/预期结果、关键代码讲解、常见错误、练习提示与参考答案、项目关联、来源、适用版本和核验日期。

示例从最小可运行起步，再逐步扩展；展示输入与输出、成功和错误路径。不得声称未实际运行的示例已验证。首次出现术语时解释，中文说明不能只翻译 API 名称。

生态库内容使用轻量模板：解决的问题、主要功能、合适/不合适场景、核心 API、简洁 TypeScript 示例、版本与官方来源。不为每个库编写长篇课程。

由 IT 教师智能体起草；技术审校者运行和核验示例，教学编辑检查易懂度；内容保持草稿，审阅通过后才可纳入交付。见[教师智能体规范](./agents/it-teacher.md)。

## 8. 本地数据与隐私

- 学习状态、节奏和偏好仅写入当前浏览器或 App WebView 的 localStorage。
- 不向服务器发送用户进度，不使用账号、数据库、云端同步、行为分析或手动备份功能。
- 静态课程内容打包在站点中；更新内容需要重新构建并部署，但本项目只计划一次性交付当前版本。
- 明确告知用户清除本地数据/卸载 App 会丢失对应设备记录。

1. 学习者可选择方向和基础程度，并看到阶段、技术节点、先修和并列关系。
